int match_regex ( const char * string,
const char * pattern )

Validates a string against a specific regex pattern.

This acts as a wrapper around the thirdparty tiny-regex-c library. It strictly determines if the sequence structurally matches complex tokens such as standardized ID formulations and specific date formats, returning a simple boolean abstraction for the lexer.

Parameters
stringThe null-terminated input string to be evaluated.
patternThe regex pattern used to validate the string structure.
Returns
Returns 1 (true) if a match is found, or 0 (false) if it is disjoint.
